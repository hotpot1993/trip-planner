## 三、最容易被用户误解 / 最容易过期的规则

1. **放票时刻没有一个是「零点」。** 目前确认的时刻：故宫 20:00、国博 17:00、陕历博 17:00（秦汉馆 17:30）、湖南博物院 20:00、湖北省博 **17:18**、成都博物馆 19:00、三星堆 20:00、泰山 10:00。尤其湖北省博的 **17:18** 和泰山的 **10:00**（2024 年由 0 点改为 10:00）最反直觉，按「0 点抢票」的旧攻略一定会错过。
2. **湖南博物院 2026-07-27 起刚从「提前 7 天」改为「提前 5 天」（不含当天）。** 这是本次调研中唯一确认的「刚改过且网上旧攻略全错」的规则，放票日算错一天就直接白跑。
3. **上博人民广场馆「免预约」是有条件的，且当前正处于条件生效期。** 该馆 2025-09-01 起试行散客免预约，但官方同时写明「国定假日、寒暑假以及举办热门特展等参观高峰期间仍需预约」；而官网首页现在挂着的「世界树之巅：美洲古代文明大展」（展期 2026.07.09–2027.11.14）明确要求「预约购票后前往人民广场馆参观」。所以**现在去人民广场馆实际要预约购票**，只看「免预约」三个字会吃亏。另外上博官网域名 2026-09-01 起改为 `www.shanghaimuseum.cn`，旧域名 2027-01-01 停用。
4. **布达拉宫「提前十天以内」不是「提前十天」。** 官方原文是「提前十天以内」，且购票成功后从参观当日起 7 日内无法二次订购；当天还需提前 1 小时到正门安检口。
5. **莫高窟不预约等于白跑，而且跑错地方也白跑。** 必须先到「莫高窟数字展示中心」，窟区不设售票处和游客停车场；常规票单日限额仅 6000 张。

## 四、我**没有**采用的说法（流传很广但找不到官方来源）

| 说法 | 为什么不用 |
| --- | --- |
| 「秦始皇帝陵博物院提前 7 天预约」/「提前 10 天」/「每日 0 点更新第 7 天票源」/「每日 17:00 整点放票、可约未来 5 天」 | 四个说法互相矛盾，且**官网《购票须知》与官方公众号全文都没有这些字样**。已核查官方页面：限流（每日 6.5 万人）、实名制、「限量、预约、错峰」、分时检票、无闭馆日——均在；提前天数与放票时刻——均无。故 `advance_days`、`release_time` 填 `null` |
| 「泰山门票提前 7 天、**每日 0 点**放票」 | 与官方通告直接冲突。泰山景区管委会 2024-06-20 通告已把线上放票时间由 0 点**改为每日上午 10:00**。二手文章（含部分 2026 年文章）仍在写 0 点 |
| 「三星堆每日 20:00 放票、提前 5 天」当作「馆方官网公告」 | 官方渠道确实有这个口径，但出处是广汉市政府网站刊登的**馆方答复**，不是官网规则页，所以 `source_kind=authority`、`confidence=medium`，并注明证据性质 |
| 「黄山风景区门票提前 3 天预约」 | 官方原话是「**建议**您至少提前三天完成预约」，是建议而非放票规则，故 `advance_days=null` |
| 「九寨沟门票提前 3 天预约」/「提前 7 天」 | 官方只写「建议提前 3-7 天预约」，未公布固定放票周期 |
| 「南京博物院每日 18:00 放票」「提前 7 天」 | 只在本地生活类二手站点出现，官网公告未写，故留 `null` |
| 「故宫提前 7 天**0 点**放票」 | 官方写明是「参观前 7 日 **20:00**」 |
| 「兵马俑/国博/故宫可现场买票，或可在携程美团买官方票」 | 三家都明确声明**从未授权任何第三方**代理门票；兵马俑官方还写明「务必完成网上购票后再前来参观」，现场人工窗口仅向不便使用智能手机的老年人提供便利 |
| 「湖北省博物馆放票 24:00」 | 是**旧版**系统的时刻；新版系统公告已明确由 24:00 改为 17:18 |

## 五、使用建议（对「路书」产品）

1. `advance_days` 为 `null` 的条目（九寨沟、黄山、兵马俑、南京博物院、上博两馆），前端不要显示「提前 N 天抢票」这类硬承诺，改为「须提前线上预约，具体放票口径出行前请以官方渠道为准」并附官方电话。
2. 所有 `confidence=medium` 的条目建议在页面上标注「规则可能调整，出行前请复核」，并给出 `evidence_url`。
3. 每次出行前，对 `release_time` 明确写死的 8 个景点做一次批量复核（爬 `evidence_url` 即可），因为放票时刻是官方最容易静默调整的字段（泰山、湖北省博都改过）。
