# 导出路书不包含地图

## 背景与决策

路书是确认后导出的、只读的单文件交付物，用途是在手机上离线查阅。它天然与两个约束冲突：单文件不能依赖构建产物，离线可读不能依赖任何在线服务。

通行做法是在导出页里内嵌一个轻量地图库加开放瓦片源（travel-plan-viz 即如此）。我们放弃了这条路。

决策：**导出路书不含交互地图，只保留每个地点的导航深链**。理由是四条独立的成本同时消失：不再需要在页面里引外部地图库与瓦片源（因而不再受境内可达性影响），不再有坐标系转换这条易错的边，不再需要把地图服务密钥埋进一个会离开本机的文件，单文件体积与外部请求数同时降到几乎没有。

## 后果

- 路书页面需要在没有地图的情况下仍然让人看懂空间关系，因此每日行程必须依靠顺序、时间段与路段的文字描述（距离、耗时、交通方式、起终点）来补偿，这块内容要做足。
- 导航深链成为路书与地图之间的唯一连接：从页面点一下跳到手机上已装的地图应用，而不是在页面里看地图。
- 这条决定与坐标统一存 GCJ-02 共同生效后，当前代码库里不存在 GCJ-02 转 WGS-84 的转换路径。如果未来要在路书里加回地图，两件事必须一起做。
